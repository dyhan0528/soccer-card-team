# 오늘만 축구 선수였다면

친구 사진을 올리고 이름·능력치를 적으면 FIFA 스타일 선수 카드가 만들어지는 단일 페이지 웹앱입니다. 친구마다 카드를 따로 만들고 PNG로 저장해 공유할 수 있습니다.

## 기능
- 사진 업로드(배경 제거 PNG 권장) + 확대·상하좌우 위치 조정, 드래그 이동
- 이름·포지션·등번호·팀 이름, 6능력치(스피드/슈팅/패스/드리블/수비/피지컬)
- 능력치 평균 자동 총점, 무작위 채우기
- 카드 색 4종(잔디/야간경기/트로피/레드카드)
- 마우스 틸트 + 포일 반사, 여러 명 카드(우리 팀) 관리
- PNG로 저장(내보내기)

## 기술
- 빌드 없는 정적 단일 `index.html` (Canvas 2D 렌더링)
- 웹폰트: Black Han Sans, IBM Plex Sans KR

## 배포
`vercel.json`의 `cleanUrls` 설정으로 Vercel에 정적 배포됩니다. GitHub 저장소를 Vercel에 연결하면 `main` 브랜치 push마다 자동 재배포됩니다.
